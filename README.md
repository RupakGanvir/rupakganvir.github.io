## ⚙️ Local Setup

Clone the repository:

```bash
git clone https://github.com/rupakganvir/rupakganvir.github.io.git
```

Navigate to the project:

```bash
cd rupakganvir.github.io
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
